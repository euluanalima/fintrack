# Changelog

Todas as mudanças relevantes do FinTrack serão registradas neste arquivo.

## [1.0.0] - 2026-09-15

### Adicionado

- Aplicação web responsiva em Streamlit.
- Cadastro e login com Supabase Auth.
- Banco PostgreSQL no Supabase.
- Row Level Security para isolamento de dados.
- Registro de receitas e despesas.
- Categorias e filtros de transações.
- Dashboard com indicadores financeiros.
- Gráficos com Plotly.
- Metas financeiras e cofrinhos.
- Depósitos e retiradas em metas.
- Prazo opcional para objetivos.
- Sincronização de dados entre dispositivos.
- Deploy no Streamlit Community Cloud.
- Regras locais de senha forte.
- Endurecimento das permissões da função automática de RLS.
