# Capturas de tela do FinTrack

Esta pasta é destinada às imagens utilizadas no README e no portfólio.

## Arquivos sugeridos

Salve as capturas com estes nomes:

```text
login.png
dashboard.png
transacoes.png
metas.png
mobile.png
```

## Recomendações

- Não use contas com e-mail pessoal visível nas capturas.
- Não mostre senhas, tokens, chaves ou informações privadas.
- Use dados fictícios nas transações e metas.
- Para a imagem mobile, faça uma captura em um celular ou emulação de viewport estreito.
- Prefira imagens em PNG com boa resolução.

Depois que as imagens forem adicionadas, elas podem ser exibidas diretamente no README principal.
